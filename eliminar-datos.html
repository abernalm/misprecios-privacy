Eliminación de datos

Aplicación: Mis Precios

La aplicación Mis Precios permite a los usuarios eliminar completamente sus datos personales en cualquier momento.

¿Qué datos almacenamos?

  • Códigos de productos
  • Descripciones
  • Precios asociados a almacenes
  • Datos de autenticación mediante Google Sign-In

¿Cómo eliminar tus datos?

Puedes eliminar todos tus datos directamente desde la aplicación siguiendo estos pasos:

  1. Abre la app Mis Precios
  2. Accede a la pantalla principal
  3. Presiona el botón "Eliminar datos definitivamente"
  4. Confirma tu identidad con tu cuenta de Google

¿Qué sucede al eliminar los datos?

  • Se elimina tu cuenta
  • Se eliminan todos los datos almacenados en Firebase
  • Se eliminan los datos almacenados localmente en tu dispositivo

Este proceso es inmediato y permanente.

Retención de datos

La aplicación no conserva datos después de su eliminación.

Para más información puedes consultar nuestra Política de Privacidad
